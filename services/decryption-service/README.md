# Decryption service

Attested decryption for Solana Privacy Rings (SPR). A sender can pay a Solana
address before its owner registers a shielded wallet. The owner signs each
decrypt batch. The enclave encrypts the reply to a key generated by the
recipient wallet. The transfer publishes the recipient's Solana address as its
owner tag.

From `services/decryption-service`, run `just ci` for Rust and TypeScript
checks and `just headless-e2e` for send, claim, and sweep on localnet.
The enclave and release tool share a service lockfile because QOS pins
`libc` independently of the Privacy Rings workspace. The enclave uses this
checkout's SPR keypair crate. The wire protocol and Rust devnet test use
the root Cargo workspace.
